# IF / ELSE in Python 

## Purpose 
IF / ELSE statements are used to make decisions in programs.

## Syntax

if condition:
     # code
elif condition:
     # code
else condition:
     # code

## Important Notes
- Indentation is very important
- Conditions return True or False
- elif means "else if"

## Comparison Operators

- (==) Equal to 
- (!=) Not equal 
- (>) greater than
- (<) less than 
- (>=) greater than or equal 
- (<=) less than or equal 

## Logical Operators
- and
- or
- not
