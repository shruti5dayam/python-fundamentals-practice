# Python Operators

## Arithmetic Operators

- ADD (+)
- Subtract (-)
- Multiply (*)
- Divide (/)
- Percentage (%)
- Power (**)
- Whole Division (//)
--------------

## Comparison Operators

- (==) Equal 
- (!=) Not Equal 
- (>) Greater than 
- (<) Less than 
- (<=) Greater than or equal to 
- (>=) Less than or equal to 
----------------

## Assignment Operators
- (=)
- (+=)
- (-=)
- (*=)
--------------

## Logical Operators
- AND 
- OR
- NOT

-----------------

## Important Notes 
- ( / ) gives float result 
- ( // ) gives integer division 
-  ( % ) gives remainder 
- ( ** ) is power operator
