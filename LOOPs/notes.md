# Python Loops

## Purpose
Loops are used to repeat code multiple times

------

# Types of Loops

## FOR Loop

Used for iterating over sequences.

Syntax:

         for item in sequence
             code 
     



------

## WHILE Loop
Runs while condition is True.

Syntax: 
           
      While Condition:
              #code


-----

# Important Keywords

## break
Stops loop completely.

## continue 
Skips current iteration.

------

# range()

range(start, stop, step)

example:
range(1,6)

OUTPUT: 
1 2 3 4 5
