# Variables

## Definition

Variables are containers used to store data in Python.
They help save values like:
- names
- numbers
- prices
- API responses
- User Data

---
## Syntax
variable_name = value
Examples:
name = "Shruti"
age = 24
---
## Rules for Variable Names
GOOD:
user_name
total_prize
student_age

BAD:
1name
user-name
class
---
## Common Data Stored in Variables
- strings
- integers
- floats
- booleans
- lists
- dictionaries
-----
## Common Mistakes
### 1. Using spaces
BAD: 
user name = "Shruti"
GOOD: 
user_name = "Shruti"
---
### 2. Forgetting quotes for strings
BAD:
name = Shruti
GOOD: 
name = "Shruti"
----
### 3. Overwriting variables accidentally
age = 24
age = 30
--- 
## Backend Connection 
Backend applications use variables constantly for:
- usernames
- passwords
- API responses
- database records
- tokens
- calculations

Example:
user_id = 101
api_status = 200
