
# Python Functions

## Purpose 
Functions are reusable blocks of code.

They help:
- Organize code
- Avoid repetition 
- Improve Readability 

------

# Syntax

     def function_name():
        # code


----

# calling a Function 
     function_name()

-----

# Parameters

Parameter () allow functions to accept values. 

Example:

     def greet(name):
          print("Hello", name)



------

# Return Statement

return sends value back from function.

Example: 

       def add(a,b):
           return a+b


---- 


# Important Notes

- def keyword creates function
- functions should have meaningful names
- return is optional
