
# Python Scope 

## Scope 
Scope means where a variable cna be accessed in a program. 

-----
# Types of Scope

## Local Scope 
Variable created inside a function. 

Accessible only inside that function. 

-----
## Global Scope 
Variable created outside function. 

Accessible throughout the program. 

------

# Important Notes

- Local variables exist only inside function
- Global variables exist everywhere
- Functions prefer local variables first
- Avoid excessive global variables in large projects
